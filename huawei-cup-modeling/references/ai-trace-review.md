# AI 痕迹检测与分级评阅

用于用户要求检测论文的“AI 痕迹”“整体 AI 感”或给出 A–E 等级。前九项检查可观察的表达与证据问题，第十项汇总。默认交付评阅报告，不修改原文；用户同时要求润色时，再按 [学术表达指南](academic-writing.md)改写并复核事实。

本流程是规则式写作评阅，未包含经校准的作者来源分类器。将用户所说的“AI 生成概率”字段标为“无法由本量表估计”，另给有证据支持的模板化表达分数与等级；不把分数加上百分号或映射为生成概率，也不根据等级认定作者身份或违规。继承主 Skill 的实时赛题规则、材料保密和锁稿要求。

## 评阅准备

- 确认范围：全文、指定章节或片段；保留文件版本和可定位的段落编号。只有扫描件时先核对文字识别质量，断句、乱码和分页碎片不作为表达缺陷计分。
- 根据现有材料确认学术文体、官方模板和作者已提供的写作样例；将模板固定内容、直接引语、参考文献条目的格式与正文表达区分开。
- 除正文外，记录是否实际查看了图表、图题、摘要与结论、参考文献及相关实验记录。只提取到 PDF 文字时，不能声称检查了配色、坐标或图表版式。
- 逐项使用“已检查”“待核验”“不适用”状态。“没有提供图表”和“全文确实不需要图表”是不同情况；仅后一种可将图表维度记为不适用。

## 全文扫描与句级定位

全文体检按章节逐段检查，不静默抽样后声称覆盖全文。先给段落和句子分配稳定编号，例如 `sec02-p003-s02`，保留原稿版本、章节、段首和可用的页码或行号。句界结合上下文识别，不把小数点、公式或参考文献编号误当断句。

维护简短的扫描进度：`章节 / 段落总数 / 已检查数 / 未完成位置 / 图表与来源核验状态`。长文分批处理时在章节边界保留进度，继续未检查部分；只能完成部分时明确标为阶段报告。文章里没有问题的段落也应进入已检查计数。

先广泛定位候选，再核对上下文、模板要求和证据。最终区分“已确认的表达或证据问题”“待核验疑点”“已排除的正常表达”，仅已确认项进入问题计数与评分；不为实现“宁多勿少”而把候选一律判错。全文风格前后不一时，先排除公式推导、结果报告、直接引用等文体差异，再定位实际术语、人称或表达习惯冲突。

短报告可以合并重复问题，但须保留全部对应位置。用户同时要求改写时，为每条确认问题给出 `原句 → 修改理由 → 建议改写 → 保留的事实 / 待核验项`；证据不足时说明补证据的动作，不编造一条貌似完整的替代结论。

## 九个观察维度

### 1. 词汇层：高频套话、空洞形容词、模板化动词

定位反复出现的空泛表述，例如“显著提升”“全面优化”“有效赋能”“深入分析”，检查它们是否缺少具体对象、指标、动作或证据。术语搜索与词频可用于找位置，但不能靠命中单词直接计分。

证据应包含原句、出现位置及缺少的信息。专业术语、准确的评价用词和任务必要的重复不扣分，也不维护未经验证的“AI 专用词”黑名单。

### 2. 句式层：单一结构、过渡滥用、主语不明

检查连续句子是否重复同一开头或句法骨架，“进一步”“因此”等是否确实表达关系，以及被动表达是否隐去了必要的执行主体。存在可读性或逻辑损失时再标记。

被动语态、客观语气和同类实验的平行表述可以保留。不能将少用第一人称或使用规范学术句式本身视为缺陷。

### 3. 段落层：均匀长度与机械结构

检查“总—分—总”是否造成段首段尾复读、同长度段落是否混合或截断论证。需要描述长度分布时使用实际计数，说明计数范围，并排除标题、公式、列表和 OCR 伪段落。

相近字数和固定段落结构只用于定位候选问题；必须进一步说明冗余或论证受损之处。不要为制造变化而推荐随机拆段。

### 4. 逻辑层：过度圆满、缺乏边界审视

检查文字是否把待验证解释当成事实、跳过从结果到结论的关键步骤、忽略已出现的反例或适用条件，以及把局部有效写成普遍成立。对照假设、结果与限制，定位具体的论证缺口。

完整推导和严密逻辑不扣分。不强求每段自我质疑，不将没有失败叙事视为缺陷；需要建议补充的是实际边界分析，而不是编造失败经历。

### 5. 作者表达：个人判断与真实取舍

按用户所说的“人味缺失”检查可观察内容：在需要解释模型选择或结果含义的位置，是否只有泛泛评价，缺少已有材料支持的选择依据、解释或取舍。已有作者样例时可比较措辞习惯，不能凭空假设其个人风格。

口语、第一人称、犹豫和不完美表述均不是必备项；它们缺席不扣分，出现也不减分。评阅不奖励错字、跳跃、闲话或刻意的不流畅。

### 6. 数据表述：精度、误差与验证范围

检查有效数字是否有依据、同一指标的精度是否一致、误差含义是否交代，以及结论是否超出样本和实验范围。必要时回查实验输出；没有原始记录时，区分“正文未说明依据”和“数值错误”，不能直接断言造假。

四位或更多小数有计算用途时保留。确定性计算、精确计数和单次运行不能机械要求加“±”；不确定性的呈现方式应由实际研究方法决定。数据适用范围的缺口在本维度主记，避免又在逻辑层重复累计同一问题。

### 7. 图表层：空泛标题、配色与标注

核对图题是否明确对象、指标与条件，坐标、单位、图例、色标和误差说明是否足够，以及配色、线型或标记能否区分类别。标题可说明已验证发现，不能为表达鲜明而编造结论。

默认配色本身不扣分；只记录确实存在的辨识困难、跨图颜色语义冲突或信息缺失。未看到实际图像时，配色与标注状态为待核验。居中与导出问题按 [图表指南](figures-and-tables.md)列为具体排版问题。

### 8. 全文结构：摘要、章节与结论

对照题目和官方模板，检查摘要是否只有算法清单、章节是否机械套用而没有回应子问题、结论是否逐句复述摘要且缺少对已验证结果的综合。

四段式摘要、常见章节名和模板规定的顺序不扣分。结论可以重述关键结果；只有无信息的复读或功能缺失才标记。未提供摘要、结论或全文结构时，不猜测其内容。

### 9. 引用与参考文献：位置、相关性与支持关系

检查关键论断是否有对应来源、引文是否支持相邻主张、编号是否对应，是否存在没有正文用途的堆砌文献。联网核验时优先采用论文原文、出版方或 DOI 元数据，记录实际查到的结果；未查到的条目标为待核验，不直接称为伪造。

统一格式是排版要求，固定位置可能来自引用规范，两者本身均不扣分。仅有参考文献表时，不能评价引文与正文的对应关系。格式错误、来源真实性问题与作者来源判断分开报告。

## 证据记录与去重

每个非零分维度至少给出一个可定位的问题，说明它为何影响表达或证据。重复性、跨章节性判断需要列出多处位置，不凭一句话推断全文风格。

每条问题记录：`问题编号 / 主维度 / 位置 / 原文短引或图表描述 / 具体问题 / 已排除的正常解释 / 修改建议`。Markdown 可用标题与行号，Word / PDF 可用页码、段落开头或图表编号；未渲染时不编造页码。

另外记录问题状态和修订状态：问题可为“已确认 / 待核验 / 已排除”；修订可为“未处理 / 已改写 / 已复核 / 保留原文并说明原因”。同一编号贯穿诊断、改写与复核，避免报告与最终文本脱节。

同一问题只在主维度计分，其他维度可以交叉引用。例如，“显著提升”没有误差或检验依据时，主记数据表述；只有另有词汇层证据时才给词汇维度加分。文献无法核验和数据错误另列来源或科学性问题，不据此直接推断 AI 使用。

## 10. 综合评分与 A–E 等级

以下是本仓库定义的编辑量表，阈值用于一致地安排修改优先级，未作来源识别的统计校准。第十项是前九项的汇总，不作为第十个维度重复计分。

### 单维度评分

| 分数 | 含义 | 所需依据 |
| --- | --- | --- |
| 0 | 在已检查范围未发现该类缺陷 | 说明核对范围或给出恰当表达的例子 |
| 1 | 孤立、轻微问题 | 至少一处位置，局部修改即可 |
| 2 | 同类问题多次出现，影响局部表达或论证 | 多处位置及其具体影响 |
| 3 | 问题跨章节反复出现 | 至少两个章节中的证据及共同模式 |
| 4 | 问题系统性存在，显著妨碍理解或证据核对 | 多章节代表性证据，说明总体影响 |

片段中的严重科学错误可单列高优先级问题，但不假设它在全文重复以获得 3–4 分。缺材料不记 0 分，不适用不记满分；需要核验才能决定评分的维度暂不打分。

### 覆盖要求与计算

1. 九个维度先确定状态；只有“已检查”且证据足够的维度进入计算，不适用维度说明原因。
2. 全文综合分要求：实际已查看全文及相关图表等材料、适用维度均已完成检查，且至少六个维度可评分。这个下限是仓库的评阅覆盖预设，不是统计有效性的证明。
3. 仅有片段、适用维度尚待核验或少于六项可评分时，仍交付已完成的逐项评阅，综合分和 A–E 等级写“暂不评定”，不要把局部结果外推到全文。
4. 满足覆盖要求时，设可评分维度数为 `n`，各维度分数为 `s_i`，计算 `S = 100 × Σs_i / (4 × n)`。九项等权；用原始计算值确定等级，展示分数四舍五入至一位小数。分数单位为“分”，不写“%”。
5. 同时报告 `已评分 n / 9`、不适用项及理由、已检查文件版本。A–E 不能替代逐项证据和问题优先级。

| 等级 | 原始综合分 S | 模板化表达程度 | 建议动作 |
| --- | --- | --- | --- |
| A | 0 ≤ S < 20 | 低 | 保留有效表达，修正局部问题 |
| B | 20 ≤ S < 40 | 较低 | 定点处理重复或空泛内容 |
| C | 40 ≤ S < 60 | 中等 | 梳理重点段落及证据衔接 |
| D | 60 ≤ S < 80 | 较高 | 优先重组存在共性问题的章节 |
| E | 80 ≤ S ≤ 100 | 高 | 系统审阅结构、表达与证据对应 |

例如，九项评分为 `2, 1, 2, 1, 0, 1, 0, 2, 0`，总分 `25.0 / 100`，等级 B；只能解释为量表中的模板化表达程度较低，不能解释为“25% 由 AI 生成”。分数相同的文章可以有不同的问题分布，应依据具体问题制定修改顺序。

## 问题文本覆盖率：使用实际标注计算

用户要求“AI 痕迹全文占比”时，提供可复算的**已确认问题文本覆盖率**，同时说明它与 AI 来源无关。与 A–E 编辑量表分数分开显示，不能互相换算。

- 固定一份 UTF-8 纯文本，保留原始换行与 SHA-256；文中每个字符的偏移指 Python 解码字符串的索引，零起算、左闭右开，不是字节或 JavaScript UTF-16 索引。
- 以排除范围之外的非空白字符为分母，标点、数字和字母均计数。封面、模板固定文字、参考文献条目、代码与不纳入语言检查的公式等如需排除，提前列明区间及理由；引文支持关系、数学正确性和图表检查仍在相应维度另行记录。不能为了降低比例临时排除有问题的正文。
- 对已确认问题标记最小有意义区间，不用整个段落替代一句话的问题。跨维度重复与重叠区间按并集计数；待核验区间单列，不混入确认问题。同一字符同时被确认为问题和列为待核验时，统计上按确认问题计一次。
- 同时报扫描覆盖率、已检查部分的问题覆盖率和待核验覆盖率。全文未扫完或输入只是片段时，不提供全文问题覆盖率；无精确标注时写“未统计”，不凭印象补数字。文字扫描完成也不代表图表或引用核验完成，不据此绕过 A–E 的覆盖要求。

计算命令相对 Skill 根目录：

```bash
python3 scripts/measure_review_coverage.py PAPER.txt ANNOTATIONS.json
```

标注 JSON 格式如下。`TEXT_SHA256` 替换为该文本文件原始字节的 SHA-256；示例区间仅适用于至少八个解码字符的文本，实际区间应逐项从已核对的原文定位：

```json
{
  "text_sha256": "TEXT_SHA256",
  "scope": "full_paper",
  "reviewed_spans": [[0, 8]],
  "excluded_spans": [],
  "confirmed_issue_spans": [[0, 2]],
  "pending_issue_spans": [[4, 6]]
}
```

`scope` 为 `full_paper` 或 `excerpt`；`reviewed_spans` 和 `confirmed_issue_spans` 必填，其余两个区间数组可省略。全部区间必须在文本内，问题区间中的可计数字符必须已检查。正文改变后重建标注，不沿用旧哈希和偏移。

脚本仅统计已给定标注，不完成语义检测。`review_coverage_pct` 是文本扫描覆盖率；`confirmed_issue_pct_of_reviewed` 和 `pending_issue_pct_of_reviewed` 的分母为已检查字符数。只有申明为全文且全部可计数字符已检查时，才给出 `confirmed_issue_pct_of_full_text`，否则为 `null`。`ai_generated_probability` 始终为 `null`。原始计数、分母与文本哈希一并输出，报告应保留这些依据。

## 报告与改写衔接

默认先给结论摘要，再给九维表、关键问题和修改优先级。报告至少包含以下字段，篇幅随材料规模调整：

```text
评阅范围与版本：
方法：规则式写作评阅，非作者来源分类
材料覆盖：正文 / 图表 / 摘要与结论 / 引文对应及必要来源核验
逐段进度：已检查段落 / 总段落；未完成章节与位置
综合分与等级：S / 100，A–E；覆盖不足则暂不评定
已评分维度：n / 9；待核验项 / 不适用项及原因
AI 生成概率：无法由本量表估计
问题文本覆盖率：分子 / 分母 / 去重与排除口径；未统计或仅片段须说明
待核验覆盖率：单列；不混入确认问题

逐维结果：维度 | 状态 | 0–4 分 | 位置与证据 | 正常解释或材料限制
关键问题：问题编号 | 主维度 | 句级位置 | 原句 | 状态 | 影响 | 修改建议
改写对照（要求润色时）：问题编号 | 修改理由 | 改写后 | 事实核对 | 修订状态
修改优先级：先修科学含义和证据，再修结构、句子与措辞
仍需核验：实际缺少的来源或材料
```

用户只要求检测时不擅自改稿。用户同时要求“检测并去 AI 味”时，完成报告后按 [学术表达指南](academic-writing.md)修改有证据的问题，保留必要 AI 披露，并逐项核对数字、单位、公式、引用和结论范围。需要前后对比评分时使用同一版本范围与同一量表；覆盖变化时不宣称分数直接可比。

验收以问题关闭、事实保留和论证清晰为依据，不承诺检测通过率，不通过补口语、删误差说明、故意制造错字或改乱引文格式降低分数。

交稿前体检同时按 [论文指南](paper-and-compliance.md)核对 AI 使用记录、人工审查证据和当届披露要求。AI 生成的体检报告自身也需要复核；低模板化分数、低问题覆盖率与提交合规是不同结论。
