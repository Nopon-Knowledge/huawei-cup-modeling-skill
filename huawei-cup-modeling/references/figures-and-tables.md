# 图表质量与居中排版

在生成、润色或审阅竞赛图表时使用。本指南提供版式默认值；当届官方模板和用户指定的载体优先。图表美化保持数据与统计含义不变，不能通过删点、截轴或手工改数制造更好的结果。

## 先明确图表要回答什么

从已保存的实验输出读取数值，关联结果账本中的 `claim_id` 和实验中的 `run_id`。先用一句话描述要展示的比较、趋势、分布或机制，再选择图型；同一信息只保留有解释价值的图或表。

| 要回答的问题 | 优先考虑 | 检查重点 |
| --- | --- | --- |
| 方法或方案谁更好 | 排序点图、条形图、紧凑结果表 | 统一指标方向、测试范围；重复实验说明不确定性 |
| 指标随时间或参数如何变化 | 折线图、点线图 | 横轴真实间隔、缺测断点、基线和必要的区间 |
| 数据如何分布、异常在哪里 | 直方图、箱线图、散点图 | 分箱依据、样本量、离群值处理；小样本展示观测点 |
| 预测偏差来自哪里 | 预测与观测散点图、残差图 | 参照线、同量纲、系统性偏差 |
| 参数交互与敏感性 | 热力图、小多图 | 色标范围、中心值、不同面板的尺度可比性 |
| 模型如何连接输入与输出 | 流程图、结构图 | 方向一致、分支标签明确、回路可读；避免箭头穿字 |

柱形或面积编码通常从零起；若使用非零范围或对数轴，明确标注并说明原因。折线和散点的轴限按分析目的设置。不要用装饰性 3D、无意义双轴或过度平滑掩盖差异；缺失值不填成零。

## 统一视觉语言

- **字体**：使用目标环境已安装、覆盖中文和数学符号的字体，并保留导出所需字体信息。按最终插入尺寸检查，常规图内文字可从 9–11 pt 起步；这些是建议，不是赛事硬性字号。
- **颜色**：同一模型在全文保持同一颜色。可用蓝 `#2563EB` 表示主模型、青绿 `#0F766E` 表示对照、灰 `#64748B` 表示辅助信息、橙 `#B45309` 表示需关注的变化；同时使用线型、标记或文字区分，不只依赖颜色。连续数值采用有序色图，有意义的中点采用发散色图。
- **线条与留白**：减弱网格与边框，让数据成为视觉重点；避免粗边框、重阴影和不必要的渐变。图例放在不遮挡数据的位置，相邻面板留出标签空间。
- **信息**：坐标写明变量与单位；误差棒或阴影区间说明是标准差、标准误还是置信区间，并给出重复次数或样本量。没有重复实验时，不编造误差区间。
- **标题与题注**：写清比较对象、指标和条件，已有证据支持时可点明发现。避免只写“XX 对比”，也不把未经验证的优越性写进标题；表达润色按 [学术表达指南](academic-writing.md)处理。
- **表格**：表头含单位；同一指标统一有效数字，小数位对齐；说明加粗、缺失值和排名符号的含义。尽量采用简洁横线，避免密集竖线；表内文字左对齐，数值按列对齐。
- **多子图**：共享字体、图例顺序和面板编号；可比较的面板统一坐标范围或明确说明差异。先减少拥挤和拆分内容，再考虑缩小字号。

## 居中与题注

“居中”指图形或表格整体相对正文版心居中，不要求每个轴标签、表格单元格都居中。还应检查图片内部留白：即使图片框居中，左右不等的空白仍会使图形看起来偏斜。

### Markdown / GitHub README

使用独立的居中段落嵌入图片，保留文字替代描述；宽图可链接到原图供放大查看。不要把 Mermaid 代码围栏塞进 HTML 容器，依赖宿主不一致的解析行为；对需要稳定布局的流程图，使用可维护的 SVG 源文件。

```html
<p align="center">
  <a href="assets/figure.svg">
    <img src="assets/figure.svg" alt="图中展示的关系与关键结论" width="800" />
  </a>
</p>
<p align="center"><sub>图 1. 简短说明比较对象、条件与来源。</sub></p>
```

需要稳定居中的表格使用 `<table align="center">`；表内按内容设置对齐。GitHub 会限制自定义样式，不能依赖 `<style>` 或外部 CSS。对其他 Markdown 阅读器，以实际渲染为准；不支持 HTML 时使用其原生对齐机制。

### Word

图片优先采用嵌入型，并设置所在段落居中；表格设置表格整体居中，数值列另设对齐。按正文可用宽度等比缩放，多子图先在绘图工具中排成一张完整图。题注采用统一样式，按模板设置位置与对齐；检查跨页时图、题注和表头是否分离。

### LaTeX

在 `figure` / `table` 环境内用 `\centering`，图片宽度不超过当前 `\linewidth`；多子图共享整体布局与间距。通常图题置于图下、表题置于表上，最终以官方模板为准。不要仅为固定位置而大量使用强制浮动选项，先检查浮动体尺寸与分页。

## 导出与实际渲染检查

统计图用 Matplotlib、R 或项目现有绘图工具生成，结构图保留 SVG 或图形源码。数值图优先导出 PDF / SVG 等载体支持的矢量格式；位图通常按最终尺寸以 300 dpi 或以上导出，不把低清截图放大后称为高清。照片、密集散点或热力图可按体积与清晰度需要栅格化，文字和坐标尽量保留矢量。

1. **保存来源**：保留数据版本、绘图脚本、运行命令与导出文件，结果对应到 `run_id` / `claim_id`。演示数据明确标为示意，不写入真实结果账本。
2. **看独立图**：检查文字覆盖、缺字、负号、图例、色标、箭头、单位与边缘裁切；确认宽高比和留白平衡。
3. **看最终载体**：在 README 或导出的论文中按实际大小检查居中、可读性、题注和分页；长图与宽表同时检查窄屏或缩印效果。PDF 中检查字体嵌入与文本提取，不能仅看绘图窗口。
4. **核对含义**：图表与账本、正文、摘要的数值、精度、样本范围和结论一致；灰度下主次仍可辨认。

发现拥挤时优先缩短标签、移动图例或拆成子图。交付时提供最终图表及复现入口，说明实际检查过的载体；没有渲染条件时标明“待视觉复核”。
